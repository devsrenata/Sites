# Sites
**Projeto Site Música**

Este projeto foi usado **HTML, CSS E BOOTSTRAP** 
O projeto tem 3 páginas.

 1. A Cantora 🎤  
Nesta seção, o usuário pode conhecer um pouco sobre a trajetória de Beyoncé, desde seu início até se tornar uma das maiores artistas da música pop. Informações como seus álbuns, prêmios e conquistas são abordadas.

2. A Música 🎼  
Aqui, o foco é nas canções mais famosas da artista, incluindo detalhes sobre os álbuns que lançaram sucessos icônicos. Uma análise dos singles mais destacados e suas significações é apresentada.

3. O Videoclipe 🎥  
Nesta parte, os usuários podem explorar alguns dos videoclipes de Beyoncé, conhecendo mais sobre a produção e o impacto visual das suas obras. A seção também conta com um carrossel de imagens que destaca momentos marcantes da carreira da artista.
